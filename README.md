# 🎬 Hybrid Recommendation System (Flask-Based)

## 🚀 Overview
This project is a **Hybrid Recommendation System** that combines **Collaborative Filtering** and **Content-Based Filtering** to provide accurate and personalized recommendations.

The system is deployed using a Flask web application, allowing users to input a movie and receive real-time recommendations.

---

## 🧠 Features
- Hybrid recommendation approach (Collaborative + Content-Based)
- Personalized Top-N recommendations
- Real-time predictions using Flask
- Simple and interactive user interface
- Improved accuracy compared to single-method systems

---

## 🔍 Approach

### Collaborative Filtering
- Uses user-item interaction data
- Finds similarities between users/items
- Recommends based on similar user behavior

### Content-Based Filtering
- Uses item features such as genres and metadata
- Computes similarity using cosine similarity
- Recommends similar items based on content

### Hybrid Model
- Combines both techniques to improve recommendation accuracy
- Reduces limitations of individual approaches
